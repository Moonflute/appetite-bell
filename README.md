# appetite-bell

A small React + Vite app for tracking appetite-related habits with a gong button, elapsed timers, and lightweight local stats.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

GitHub Pages deployment is handled by [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml).
Every push to `main` builds the app and deploys the generated `dist` output through GitHub Actions.
